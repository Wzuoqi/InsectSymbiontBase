File Format Example

Your uploaded file should contain the following columns:

  • sample_id: Sample identifier
  • taxonomic_level: Taxonomic level (phylum, class, order, family, genus, species)
  • taxon_name: Taxon name
  • abundance: Relative abundance value (0-100 or 0-1)

CSV format example:

sample_id,taxonomic_level,taxon_name,abundance
Sample1,genus,Bacillus,23.5
Sample1,genus,Lactobacillus,15.2
Sample1,genus,Escherichia,10.8
Sample2,genus,Bacillus,18.7
Sample2,genus,Lactobacillus,22.1
Sample2,genus,Clostridium,12.5
